# LifeOS Manual Explorer

A minimal, high-performance manual explorer for automotive service manuals, built with TypeScript, Lit, IndexedDB, Tailwind CSS, and Cloudflare Pages. It uses Cloudflare R2 as the remote source of truth.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
